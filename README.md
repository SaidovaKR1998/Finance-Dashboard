📌 **О проекте**
**Finance Dashboard** - Анализ личных финансов

Проект предоставляет из себя персональный инструмент для анализа финансовых операций

🛠 **Технологии:**

- Python 3.8+
- Pandas - обработка финансовых данных (для работы с Excel-отчетами)
- Requests - работа с API 
- yFinance - получение данных об акциях
- python-dotenv - управление переменными окружения

Полный список в файле *requirements.txt*

📁 **Модули и функционал:**

1. Генерация отчетов (reports.py)
- Фильтрация транзакций по категориям
- Анализ расходов за период 
- Автоматическое сохранение в файл

2. Сервисные функции (services.py)
- Обработка транзакций 
- Нормализация данных 
- Бизнес-логика приложения

3. Вспомогательные функции для страницы "Главная" (utils.py)
- Функции работы с финансами
- Функции работы с API
- Вспомогательные функции

4. Функция для страницы "Главная" (views.py)
- формирует полный JSON-ответ для дашборда, включающий: 
  - приветствие
  - данные по картам
  - крупные транзакции
  - курсы валют
  - котировки акций

5. Результат (main.py)
- модуль, запустив который, можно получить результат всех реализованных в проекте функциональностей


⚙️Тестирование
- Проект включает полный набор тестов:
- Юнит-тесты для всех модулей
- Интеграционные тесты
- Проверка стиля кода (flake8)

🚀 **Установка/Настройка окружения**

1. Клонируйте репозиторий:

git clone https://github.com/yourusername/financial-dashboard.git

cd financial-dashboard

2. Установите зависимости:

pip install -r requirements.txt

3. Создайте файл .env на основе шаблона .env.template:

cp .env.template .env

4. Заполните .env (ключи не обязательны - используются бесплатные API):

CURRENCY_API_KEY=your_key_optional  # Frankfurter.app работает без ключа

STOCK_API_KEY=your_key_optional     # Yahoo Finance не требует ключа

🔄 **Подготовка данных**
1. Поместите ваш Excel-файл с операциями в корень проекта (по умолчанию ищется operations.xlsx)

2. Формат Excel-файла:

   Обязательные колонки:
      - Дата операции (в формате DD.MM.YYYY HH:MM:SS)
      - Номер карты (можно с маскировкой ****1234)
      - Сумма платежа (отрицательная для расходов)
      - Статус (OK для успешных операций)
      - Категория, Описание, Кэшбэк
     
3. Подготовка user_settings.json

    Это файл настроек для функции *load_user_settings()* Если он не найден, используются настройки по умолчанию
